# Ravenshaw Free Fire Esports — Squad Registration

Static squad registration page that sends formatted team details directly to the tournament manager on WhatsApp (`+91 82609 82767`).

## Upload to GitHub & Deploy
1. Extract this folder and upload `index.html` and `README.md` to your GitHub repository.
2. **GitHub Pages:** Go to **Settings -> Pages**, choose your main branch and `/ (root)` folder, and click **Save**.
3. **Vercel:** Import the GitHub repository in Vercel and deploy with default static settings (no build command needed).
